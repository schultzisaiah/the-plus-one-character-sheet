# The +1 Character Sheet — for 5.5e

A single-page, browser-based character sheet for D&D 5th Edition (2024 rules), laid out like the 2024 Player's Handbook sheet. No build step and no dependencies: everything lives in `index.html`.

## Use it

- **Online:** open the GitHub Pages site for this repo.
- **Locally:** open `index.html` in any modern browser.

Your sheet is saved in your browser's local storage, so it stays on that browser and device.

## Deploying to GitHub Pages

1. Push this repo to GitHub.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, set **Source** to *Deploy from a branch*, pick `main` and `/ (root)`, then save.
4. The site will be published at `https://<username>.github.io/<repo-name>/`.

The `.nojekyll` file tells Pages to serve the files as-is without running Jekyll.
