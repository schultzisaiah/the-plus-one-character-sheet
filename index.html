Sheetwright

Import from D&D Beyond

One-time setup

Drag this button onto your browser's bookmarks bar:

⇩ Copy D&D Character

Can't drag it? , create a new bookmark, and paste the code as its URL. If you use Tampermonkey you can instead. It adds a button to every character page.

Each time
  1. Open your character on dndbeyond.com, signed in. Any tab works.
  2. Click the Copy D&D Character bookmark. It copies the full character data.
  3. Come back here and paste with Ctrl+V / ⌘V into the box below.

Your sheets are stored only in this browser. Re-import any time to pick up level-ups. Exported sheet files can be imported here too.

Export this sheet

Save a copy of the sheet, including your edits. You can import it into Sheetwright on another computer.

This hosted version can't open the print dialog or save files. To print or save a PDF, open the downloadable sheetwright.html file in Chrome and import this JSON there.

Delete ?

This removes the sheet and your edits from this browser. You can import it again from D&D Beyond later.
